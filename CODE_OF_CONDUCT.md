# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, and assume good intent. Harassment, personal attacks and discriminatory language are not tolerated.

Report unacceptable behaviour to the project maintainers by opening a private report or contacting them directly. All reports will be reviewed and handled confidentially.
